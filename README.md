# Copyhot

Copyhot 是一款本地优先的开源 PC 桌面视频工具。剪辑交互以 [Shotcut](https://github.com/mltframework/shotcut) 为上游，在其上增加热点视频的风格分析、可复用剪辑模板、本地素材库，以及用户自备密钥（BYOK）的 AI 能力。业务数据和素材默认只保存在用户本机。
