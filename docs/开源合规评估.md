## 1. 评估标准

Copyhot 自身是开源项目。选用和再分发依赖时，只要求该依赖允许被一个开源项目使用、修改并按兼容许可证再分发。不评估能否链进闭源安装包。

本项目预定许可证为 **GNU GPL-3.0**。Shotcut 上游公开说明为 GPLv3。落地锁定标签时，要抽样阅读 `src/main.cpp` 等文件头：若声明是 GPL-3.0-only（没有 “or any later version”），则本仓库使用 GPL-3.0-only，不自行标成 “or later”。若上游明确允许后续版本，再改为 GPL-3.0-or-later。

在这个前提下：

- GPL-3.0、LGPL-2.1-or-later、LGPL-3.0、MIT、BSD、Apache-2.0 可以进入本仓库。Apache-2.0 与 GPL-3.0 可以组合；与仅 GPL-2.0 的代码不能组合。组合后的作品按 GPL-3.0 分发，并保留 Apache 所要求的声明。
- GPL-2.0-only 不新引入。上游已经链接且许可证为 GPL-2.0-or-later 的库（需在锁定标签时核对 Frei0r 等）沿用上游，不另选一个 only 版本。
- 允许收费提供安装包。获得该二进制的用户有权免费取得对应源码，并在 GPL-3.0 下继续使用和分发。这是开源义务，不是闭源商用许可。

不采用、也不作为备选写进构建的组件：

- 商业专有剪辑 SDK，以及任何禁止开源再分发的条款，包括 Commons Clause、BUSL、SSPL、CC-BY-NC。
- 为了规避 GPL 而并行引入的 Web 剪辑栈（WebCut、WebAV、ffmpeg.wasm）。本项目已经选择 Shotcut，第二套媒体栈不带来许可证上的必要收益。
- 未在选定 Shotcut 标签中出现的 GPL-2.0-only 库。

## 3. 分发时要做的事

M5 分发安装包时，同一版本的仓库或随包材料需要包含：

1. 本项目的 GPL-3.0 许可证全文，以及 Shotcut、MLT、FFmpeg、Qt、Frei0r 等上游要求保留的版权与许可证文本。来源优先使用该 Shotcut 标签的 `COPYING` 和 [credits](https://shotcut.org/credits/)，并核对标签内文件，不以网站的日后变更为准。
2. 修改说明：相对选定 Shotcut 标签改了什么，或可直接提供本仓库完整对应源码（含构建脚本和锁定的上游提交号）。GPL-3.0 要求对应源码，只给一个不固定的分支名不算对应版本。
3. 关于对话框中的入口，能打开上述文本。
4. 不把上游商标当成 Copyhot 的名称。Shotcut 的名称和图标按上游商标习惯使用在「基于 Shotcut」的致谢中，产品名使用 Copyhot。

引入 Shotcut 源码树的那一次提交就要放入许可证文本。只有设计文档的提交还不构成二进制分发，因此当前仓库尚未放置 GPL 全文。

## 4. 与版权许可证分开的事项

下面各项不因「依赖可以开源使用」而自动满足。

**专利。** H.264、HEVC 等编解码可能受专利约束。GPL 与 LGPL 不是专利许可。首发沿用 Shotcut 上游的编码器选择，并在律师复核前不增加上游构建没有的编码器。

**他人作品的版权。** 用户导入的参考片、BGM 和画面是否有权使用，由用户负责。产品不做平台下载器，模板不保存参考片的画面、音轨和字幕原文，以缩小应用自身复制该内容的范围。这不构成对用户行为的法律担保。

**个人信息。** 关键帧里的人脸属于敏感个人信息。架构文档要求单独同意后才发送画面，密钥和请求正文不进日志。若以后增加账号或上传整库，需要重新做个人信息影响评估，本文的范围不再适用。

**生成合成内容标识。** 导出默认带可见的 AI 标识。《人工智能生成合成内容标识办法》及其配套标准是否把「本地客户端 + 用户自备模型密钥」列为标识义务主体，本文不作出判断，留给律师。在判断明确前，产品保持默认可关闭的显式标识，避免既完全不加标识，也在界面上写成「已满足全部法定标识义务」。

## 5. M0 核对清单

锁定 Shotcut 标签后，在合规评估的修订记录中填上提交号，并完成：

- 文件头是 GPL-3.0-only 还是 GPL-3.0-or-later
- 该标签实际启用的 FFmpeg 配置是否包含 GPL 组件（预期包含；若包含，与本项目 GPL-3.0 一致）
- Frei0r 与 Qt 开源版的许可证文本是否随上游材料提供
- credits 列表与二进制中实际携带的动态库是否一致
- whisper.cpp 若进入安装包，模型权重的许可证是否允许随 GPL-3.0 应用分发；不允许则权重改为用户自行放置，不放进安装包

任一核对失败：不发布安装包，并先更新本文再改构建。
